# Addus HomeCare

> Addus HomeCare Corporation (NASDAQ: ADUS) is a US provider of personal care, home health and
> hospice services, delivered in the home and community across roughly three dozen states. It is a
> care-delivery organization, not a software vendor: it publishes no developer program, no public
> API, no SDK and no machine-readable contract of any kind.

## Read this first

Addus HomeCare has **no public API**. If you are an agent looking for an endpoint to call, there is
nothing here to call, and no amount of further crawling will find one. Specifically, as probed on
2026-08-30:

- `api.addus.com` and `developer.addus.com` **do not resolve** (NXDOMAIN, no A record, no CNAME).
  Both appeared in an earlier API Evangelist profile of this company and were incorrect; they have
  been removed.
- `addus.com/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`,
  `/redoc` and `/graphql` all return **404**.
- Every `/.well-known/` path probed on `addus.com` returns **404**, including `security.txt`,
  `api-catalog`, `openid-configuration`, `oauth-authorization-server`, `agent-card.json` and
  `agent.json`.
- `addus.com/wp-json/` is a WordPress core REST endpoint that returns **401 `rest_not_logged_in`**.
  It is CMS infrastructure for the marketing site, not a product API, and it is closed to anonymous
  callers.
- `connect.addus.com` is a caregiver web application whose single-page-app catch-all answers HTTP
  200 with an HTML shell for **every** path, including paths that do not exist. None of its 200s is
  a document; treat them all as misses.
- No packages exist on npm, PyPI, RubyGems or crates.io. `github.com/Addus` has zero public
  repositories and no identifying metadata, and is not attributable to this company.

## Where the integration surface actually lives

Addus's system-to-system integrations are real, but they are published by its software partners
rather than by Addus, and they are scoped by contract rather than by a public developer portal:

- Clinical record and home-based care platform: Homecare Homebase (hchb.com), under a joint
  development agreement announced 2021-04-22.
- Electronic Visit Verification (EVV): CellTrak (celltrak.com), Addus's primary EVV provider.
- Payer exchange: X12 EDI and state EVV aggregators, governed by payer-specific agreements.

If you need an interface into home-care operations, those vendors are the correct place to look.
